# 飞书招聘汇总表读取工作流

## 已验证的读取方式

匿名只读表格的网格主要由画布呈现，直接读取页面正文不能取得全部单元格。右键目标记录，点击「查看详情」，记录卡片会暴露文本与投递/公告链接。卡片提供上一条/下一条记录；下一条快捷键为 Ctrl + Shift + ↓。每次操作后检查当前公司名称，避免混淆记录。

## AI 执行约定

- 优先检查 2026 年 8 月以后线索；2027 与 2026 可投相关届次取并集。筛选是否生效须从结果验证，不能仅以点击选项为依据。
- 表格更新时间、开始时间、届次标签、岗位摘要均为线索，另存原公告或招聘站核验结果。未验证的资格保持 unknown。
- 先提取有限批次公司入口，再按独立公司或岗位列表交给并行代理检查；禁止多个代理操作同一浏览器标签。
- 招聘二维码可检查目标与岗位内容。认证二维码不作为招聘链接处理；需要微信登录的入口暂停并记录 login_required。
- 网络错误、浏览器访问策略拒绝、反自动化限制与登录需求分开记录，不相互推断。当前环境对微信公众号文章的策略拒绝不能标作微信登录需求。
- 无法读取原公告时保存原链接和表格摘要，保持待核验；不得用历史招聘页证明本轮毕业资格或截止日期。
- 每次运行仅记录实际扫描范围与未完成项，不声称已经扫描整张表。真实来源记录与运行日志放在忽略的 data 目录，不提交到公开仓库。

## 本次能力边界

已确认可从记录卡片读取公司、届次、地点、岗位摘要、时间及链接。尚未确认表格批量导出或筛选持久生效；微信公众号原文及其中招聘二维码尚未完成读取。应先验证可公开读取的招聘网站能否完整返回岗位详情，再扩展批量范围。
