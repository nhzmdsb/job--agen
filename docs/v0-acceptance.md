## 额外验证

- 原有 4 项及新增必要测试共 10 项通过，包括真实 MCP stdio 工具调用、旧 envelope/未知字段保留、版本检查、历史快照原子恢复、上传文件校验、重复来源及名额规则。
- 实际同岗位并发修改：本地编辑与另一个 GitHub 客户端写入相撞，产生冲突；经本地 HTTP 明确合并后双方完整历史保存至本地及私有 `conflict-history`，再同步读回。
- 网络失败与重试：在真实 GitHub 客户端传输层注入连接失败，本地修改留在待同步；恢复真实网络请求后成功上传并清空待同步。没有切断整台电脑网络，不把此验证描述为物理断网演练。
- 垃圾桶及名额：隔离浏览器操作垃圾桶后，真实运行的 HTTP 新增同来源返回 409；同公司同批次名额为 1 时第二个岗位标记已投递弹出提醒，取消不改进度，确认后保存原因及申请历史。虚构记录不进入正式私有数据仓库。
- 历史恢复能力使用虚构、完整多版本快照验证，保留 ID、版本及历史；损坏快照不部分写入。原数据库实际为空，备份后保留；`search-pool-20261008.zip` 未找到，历史 64 个岗位没有恢复。
- JavaScript 语法检查通过。公开提交范围仅代码、文档与虚构测试数据；SQLite、设置、备份、附件、凭据未提交。
